PivotGrid KBN — Prototype (variant 2)

Prototype note. The two changes below are emulated in the demo layer on top of the stock library (nothing in the PR/library is modified) so you can feel how it should behave:
  • Field panel = one Tab stop + arrows. A small roving-tabindex controller (mirrors the built-in RovingTabIndex) turns all field chips into a single zone: Tab enters/leaves it once, ←→↑↓/Home/End move between fields — instead of one Tab stop per field.
  • Data cell shows a focus outline (CSS :focus-visible rule the shipped theme is missing for the data area).

Try the whole Tab order (now ~4 stops instead of 8)

  • Tab once → lands on the field panel (one stop). Walk fields with arrows.
  • Tab → column headers zone (arrows move within).
  • Tab → row headers zone (arrows move within).
  • Tab → data area — now with a visible focus outline.
  • On a header cell: Shift+F10 / Menu opens the context menu (unchanged from the PR).
