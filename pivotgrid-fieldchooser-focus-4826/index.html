PivotGrid — видимый фокус на кнопках тулбара

Проверка исправления issue 4826 (часть #4196). WCAG 2.4.7 Focus Visible (A), 1.4.11 Non-text Contrast (AA).

В чём была проблема

Кнопки тулбара PivotGrid («Показать список полей» и «Экспорт») создаются как dxButton со stylingMode: 'text' в Fluent и Material. У такой кнопки состояние фокуса — это лёгкая подсветка фона, которая на безрамочной иконочной кнопке практически незаметна. При этом ячейки самой сводной таблицы используют контур 2px акцентного цвета. Кнопка была в tab-порядке и получала фокус, но визуально это было не видно.

Исправление: .dx-pivotgrid .dx-pivotgrid-toolbar .dx-button:focus-visible получает outline: 2px solid $pivotgrid-accent-color; outline-offset: -2px — тот же контур, что у ячеек и иконок раскрытия. Правило добавлено в базовый SCSS, поэтому работает во всех темах, и ограничено тулбаром PivotGrid, чтобы не задеть кнопки других компонентов.

Как проверять

  1. Оставьте галочку «Фикс применён» включённой и нажимайте Tab — фокус пойдёт по кнопкам тулбара трёх примеров ниже. На каждой кнопке должен появиться отчётливый контур 2px.
  2. Снимите галочку — из собранной темы удаляется ровно одно CSS-правило (то, что добавляет фикс). Повторите обход по Tab: контура больше нет, остаётся только еле заметная подсветка фона — это состояние «до фикса».
  3. Строка «Фокус» ниже показывает вычисленный outline элемента в фокусе: до фикса это 0px none, после — 2px solid акцентного цвета.
  4. Смените тему и повторите: фикс должен работать в Fluent (light/dark), Material и Generic.
  5. Мышью контур не появляется — это :focus-visible, ожидаемое поведение (как у ячеек грида).
CSS собран локально из этой ветки; переключатель удаляет/возвращает ровно одно правило
Фокус: — (нажмите Tab)

1. Тулбар в области фильтров

fieldPanel: { visible: true, showFilterFields: true } — кнопки в .dx-filter-header

2. Тулбар в области колонок

fieldPanel: { visible: true, showDataFields: true } — кнопки в .dx-column-header

3. Тулбар в ячейке описания

fieldPanel: { visible: false } — кнопки в .dx-area-description-cell; здесь stylingMode принудительно 'text' во всех темах, включая Generic
