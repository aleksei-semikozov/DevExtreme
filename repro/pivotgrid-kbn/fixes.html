PivotGrid A11y — что починили и как это проверить

Сборка с фиксами (после тестирования). Ниже — что было → что стало, как убедиться без скринридера (через DevTools → Accessibility) и со скринридером (NVDA — гайд в конце страницы). Грид для проверки — внизу. Начни с DevTools-способа: он показывает «что скажет любой ридер», не требует Windows.

#4 — Подсказка о клавишах теперь читается FIXED

Проблема (Andrew): инструкция о клавишах висела в атрибуте aria-description. Это черновик ARIA 1.3 — NVDA/JAWS его не читают, подсказка «немая».
Было: role=menubar, aria-label="Row Fields", aria-description="Press Enter…" — description не озвучивается.
Стало: role=menubar, aria-label="Row Fields. Press Enter or Space to sort…, Shift + F10…" — инструкция вложена в имя области (как в TreeList/DataGrid), aria-description убран.
Проверить (DevTools): выдели таблицу области полей (например Row Fields) → вкладка Accessibility → поле Name теперь содержит и название области, и инструкцию по клавишам. Раньше в Name было только «Row Fields», а инструкция — в Description (не читалась).

#5 — Заголовки больше не читаются дважды FIXED

Проблема (Andrew): заголовки строк/колонок NVDA читал дважды.
Причина: мы дополнительно вешали на каждую ячейку данных aria-describedby со ссылками на заголовки. Но NVDA уже строит связь ячейка↔заголовок из grid-модели (role=grid + aria-colindex + role=columnheader). Наш атрибут дублировал её → двойное чтение.
Было: у каждой data-ячейки aria-describedby → заголовки (плюс grid-модель) = связь задаётся дважды.
Стало: aria-describedby с ячеек убран. Связь заголовок↔ячейка — только через grid-модель, ровно как в DataGrid (там data-ячейки тоже без describedby).
Проверить (DevTools): выдели любую ячейку данных → в Accessibility у неё больше нет длинного aria-describedby. На NVDA (гайд ниже): при переходе на ячейку заголовок строки/колонки звучит один раз.

#6 — Заголовок строки озвучивается как чужая колонка (AUS) подтверждённый баг — нужно твоё подтверждение на NVDA

Проблема (Andrew): при табличной навигации NVDA называет row-заголовок принадлежащим колонке данных (например AUS).
Причина: в grid-модели row-заголовки не имеют aria-colindex, а колонки данных нумеруются с 1 → в «сетке» NVDA колонки row-заголовков схлопываются с data-колонками. Это модель ролей ячеек (пришла с базовой задачей #34220), не поздние правки.
Предлагаемый фикс: зарезервировать индексы под колонки row-заголовков — row-заголовки получают aria-colindex 1..k, а данные начинают с k+1 (и aria-colcount учитывает k). Тогда «сетка» не схлопывается.
Что подтвердить на NVDA: в табличной навигации (Ctrl+Alt+←/→/↑/↓) встань на row-заголовок (Africa/Asia…) и послушай, какую колонку называет NVDA. Если чужую (AUS и т.п.) — баг подтверждён, делаем фикс индексов. (Фикс ещё не в этой сборке — сначала твоё подтверждение.)

🎧 Как проверить на NVDA (для базового QA)

Важно: NVDA существует только под Windows. Нужен ПК/ВМ с Windows (или удалённая сессия — Assistiv Labs / BrowserStack). На маке NVDA не запустится (там встроенный VoiceOver, но эксперты слушают именно NVDA).
  1. Поставить: скачать бесплатно с nvaccess.org, установить, запустить. NVDA сразу начинает читать.
  2. Модификатор NVDA: по умолчанию это Insert. На ноутбуках/маковских клавиатурах Insert часто нет → в NVDA menu → Preferences → Settings → Keyboard включить Caps Lock как NVDA-модификатор.
  3. Заглушить речь в любой момент — левый Ctrl.
  4. Браузер: Chrome или Firefox (с ними у NVDA лучшая интеграция).
  5. Открыть эту страницу, Tab в грид.
Что слушать по пунктам:
  • #4: войди Tab'ом в область полей — NVDA должен прочитать имя области вместе с инструкцией о клавишах (Enter/Space/Alt+↓/Shift+F10).
  • #5: перейди на ячейку данных — заголовок строки и колонки должны прозвучать по одному разу (не дважды).
  • #6: табличной навигацией (Ctrl+Alt+стрелки) встань на row-заголовок — проверь, правильную ли колонку называет NVDA. Если чужую — это баг #6 (подтверди, тогда чиним индексы).
Режимы NVDA: на странице по умолчанию Browse mode (курсор чтения, стрелки ходят по содержимому). Для взаимодействия с гридом NVDA сам переключается в Focus mode, либо переключить вручную NVDA+Пробел. Табличная навигация — Ctrl+Alt+стрелки.
