2. Заголовки строк (#4478 / PR #34204)

Проверить:
  1. Tab — заголовки колонок, ещё Tab — фокус на первой ячейке заголовков строк (регион). Дальше Tab уходит из грида (иконки не в tab-порядке).
  2. ↓/↑ — предыдущая/следующая строка: с региона вниз — следующий блок (Total/регион), с города вниз — следующий город.
  3. → с региона (ячейка с rowspan) — его первый город; ← с любого города — его регион-родитель.
  4. С «… Total» (colspan на оба уровня) → — никуда; с «Grand Total» ↓ — никуда. Фокус на месте, страница не скроллится.
  5. Enter/Space на регионе — collapse/expand, фокус сохраняется, aria-expanded меняется. После collapse строки городов исчезают — навигация продолжает работать.
  6. Стрелками уйти вглубь → Shift+Tab/Tab — возврат на ту же ячейку (roving).
  7. Клик по городу — он становится tab-остановкой.
  8. Включить RTL: ←/→ между уровнями следуют визуальному направлению.
