4. Поля областей: стрелочная навигация (#4452 / PR #34259) + ARIA (#4454 / PR #34271)

Что сделано. Чипы полей («Region», «Amount»…) в панели полей пивота и в попапе Field Chooser получили:
  • Roving tabindex — одна tab-остановка на область; первое (или последнее сфокусированное) поле имеет tabindex="0", остальные -1;
  • Стрелочную навигацию — ↓/→ следующее поле, ↑/← предыдущее, в пределах своей области (в RTL ←/→ следуют визуальному направлению);
  • ARIA-семантику по образцу CardView — контейнер полей: role="menubar" + aria-label с именем области («Row Fields»…); каждый чип: role="menuitem" + составной aria-label: «Field name Region, Header filter applied, Sorted in ascending order» (части появляются по фактическому состоянию).
Как проверить (панель полей — сверху грида):
  1. Tab с адресной строки: на каждую область полей (filter → data → column → row) приходится одна остановка, фокус встаёт на первое поле области.
  2. Внутри области: →/↓ — следующее поле, ←/↑ — предыдущее. На краю области фокус стоит на месте.
  3. Уйти стрелкой на второе поле → Shift+Tab → Tab: фокус вернулся на него же (roving), а не на первое.
  4. Enter/Space на поле row/column/filter — переключает сортировку, фокус на месте; Alt+↓ — открывает header filter.
  5. В DevTools (Elements → Accessibility): у строки области — role="menubar" и aria-label («Row Fields» и т.п.); у чипа — role="menuitem" и label вида Field name Region, Sorted in ascending order.
  6. Переключить сортировку поля Enter'ом — label меняется на …Sorted in descending order (чипы ре-рендерятся).
  7. Применить header filter (Alt+↓, выбрать значение, OK) — в label добавляется Header filter applied.
Field Chooser (кнопка в правом верхнем углу грида):
  1. Открыть попап — те же роли: контейнер каждой области role="menubar", чипы role="menuitem"; стрелки и roving работают так же.
  2. Перетащить все поля из какой-нибудь области (например, из Filter Fields в Row Fields) — у опустевшего контейнера роль menubar снимается (menubar без пунктов — невалидная ARIA); в панели пустая область показывает обычный текст-плейсхолдер без ролей.
  3. Скринридером (VoiceOver: Cmd+F5): при фокусе на чипе объявляется «Field name …, Sorted in …, menu item», при входе в область — имя области.
Тексты label'ов — предложение для техписателей (ключи dxPivotGrid-ariaFieldItem* в en.json, формулировки — дословный паттерн CardView): «Field name {0}», «Header filter applied», «Sorted in ascending order», «Sorted in descending order». Известное ограничение: drag-клон чипа при перетаскивании сохраняет role="menuitem" (CardView на время драга роль снимает).
