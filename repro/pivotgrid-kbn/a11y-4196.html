PivotGrid A11y — приёмка эпика #4196

Сборка от 2026-07-17: head PR #34341 (ARIA для полей областей, ветка pivotgrid-kbn-fields-aria-attrs-main) + локальный мердж актуального main — т.е. состояние «как после мерджа #34341»: включает влитые #34349 (стрелки: заголовки колонок/строк), #34350 (стрелки: поля областей), #34351 (контекстное меню с клавиатуры).

Must-have чек-лист из #4196

ПунктСтатусКак проверить здесь / что нашла локальная проверка
Expand-иконки недоступны с клавиатуры (KBN)OK Tab до области заголовков → стрелками до свёрнутой ячейки → Enter/Space разворачивает, фокус остаётся на ячейке, aria-expanded меняется. Сами иконки — tabindex="-1" (единый tab stop на область — так задумано). Авто-повтор Enter подавлен.
Сортировка колонок с клавиатурыOK Enter/Space на чипе поля (панель сверху) переключает сортировку; aria-label чипа меняется «Sort order: ascending → descending». Нюанс: атрибут aria-sort не выставляется (_setAriaSortAttribute — no-op), состояние объявляется через label чипа.
Содержимое Field Chooser недоступно с клавиатурыOK Открыть попап (кнопка справа сверху, Enter): области полей — roving tabindex + стрелки ←→↑↓, список «все поля» — dxTreeView со своей клавиатурной навигацией.
Header filter не открывается с клавиатурыOK Фокус на чип поля → Alt+↓ — попап фильтра открывается, фокус уходит в список.
Field chooser визуально не фокусируетсяOK Кнопка chooser'а и чипы получают видимую обводку при клавиатурном фокусе; для ячеек заголовков — td:focus-visible outline 2px (см. навигацию стрелками).
Некорректное описание при фокусе PivotGridOK Корневой элемент: role="group" + aria-label="Pivot grid"; grid-обёртка: role="grid" + aria-owns + aria-rowcount/colcount.
Elements must only use supported ARIA attributes (axe)OK axe-core 4.11 (aria-allowed-attr, aria-valid-attr*, aria-roles, aria-required-children/parent): 0 нарушений на этой странице.
Table headers must refer to data cellsЧастично Роли columnheader/rowheader/gridcell + общий числовой каркас aria-colindex/aria-rowindex (112/112 ячеек данных) и aria-owns на grid-обёртке. Пер-ячеечной связи headers=/id нет. axe-правила td-headers-attr / th-has-data-cells не флагуют (таблицы разнесены по областям).
Scrollable region must have keyboard access (axe, KBN)OK Первая ячейка области данных фокусируема (tab stop), скроллируемые контейнеры сознательно без tabindex. axe scrollable-region-focusable: 0 нарушений.
Header filter: в aria-label нет имени колонкиOK Состояние фильтра объявляется составным label чипа: «Field: Country, Header filter applied, …» — имя поля и факт фильтра в одном описании. Сам значок-«воронка» отдельного label не имеет (декоративен внутри чипа).
Color contrast (axe)OK* axe color-contrast на виджете (fluent.blue.light): 0 нарушений. (6 срабатываний на странице — это trial-watermark dev-сборки, не продукт.) Отдельный фикс контраста тем был влит ещё в феврале 2026 (f153a589c5).

ЗадачаСтатусКомментарий
Roving tabindex + стрелки: заголовки колонок/строк, поля областейOK#34349 + #34350 влиты в main; здесь: один tab stop на область, ←→↑↓, возврат фокуса на последнюю ячейку.
Fields aria-атрибуты (этот PR #34341)OKКонтейнеры областей с полями: role="menubar" + label («Row Fields»…), пустые — presentation; чипы: role="menuitem" + label «Field: Region, Sort order: ascending» (ключи dxPivotGrid-ariaField*).
Контекстное меню ячейки с клавиатурыOK#34351: Shift+F10 или клавиша ≣ Menu на сфокусированной ячейке — меню у ячейки, после закрытия фокус возвращается.
ARIA grid roles + aria-colindex/rowindexOKrole=grid/row/columnheader/rowheader/gridcell, colindex/rowindex на ячейках (вкл. colspan и виртуальный скролл).
Полная ассоциация заголовков с ячейками (headers=/id)НетНе реализована; сейчас связь только через общий colindex/rowindex-каркас + aria-owns. Единственный незакрытый пункт «Table headers refer to data cells».
Фокус на кнопку при закрытии попапа chooser'аOKEsc в попапе → фокус возвращается на кнопку field chooser (проверено).
ТестыOKJest pivot_grid: 45/45 (вкл. a11y.test.ts); QUnit «PivotGrid accessibility markup»: 20 тестов; e2e kbn/: 5 файлов, 26 сценариев.
Локальная проверка 2026-07-17: puppeteer + axe-core 4.11.3, Chrome headless; полный прогон axe по странице — нарушения только вне виджета (watermark dev-сборки, отсутствие landmark'ов на самой демо-странице). Известные мелочи (не блокеры): нет aria-sort на сортированных чипах (состояние в label); drag-клон чипа сохраняет role="menuitem" на время перетаскивания; у незасортированных полей label объявляет «Sort order: ascending» по умолчанию.
