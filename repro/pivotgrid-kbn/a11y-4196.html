PivotGrid A11y — приёмка эпика #4196

Сборка от 2026-07-17 (вечер): head PR #34341 + main + PR #34375 целиком (все 4 этапа): axe-тесты, aria-description на областях полей, контекстное меню чипов с клавиатуры, NEW: ассоциация ячеек данных с заголовками через aria-describedby. С этой сборкой закрыты все must-have пункты эпика.

Как тестировать руками

А. Клавиатура (без скринридера, 3 минуты)
  1. Tab с адресной строки: кнопка Field Chooser → по одной остановке на область полей (filter/data/column/row) → область заголовков колонок → область строк → первая ячейка данных. Никаких «лишних» остановок на каждой иконке.
  2. На чипе поля: Enter/Space — сортировка (стрелка на чипе разворачивается); Alt+↓ — открылся header filter, Esc — фокус вернулся на чип.
  3. На чипе поля: Shift+F10 (mac: fn+Shift+F10) — контекстное меню у чипа («Show Field Chooser»), Esc — фокус вернулся на чип. То же на ячейке заголовка колонок (там ещё Expand All/Collapse All).
  4. В заголовках: стрелки ходят по ячейкам, Enter на свёрнутой — разворачивает, фокус на месте; уйти Shift+Tab и вернуться Tab — фокус на той же ячейке (roving).
  5. Открыть Field Chooser (Enter на кнопке) → внутри те же стрелки/Enter/Alt+↓; Esc — попап закрылся, фокус на кнопке.
Б. DevTools → Accessibility (что «скажет» любой ридер, 2 минуты)
  1. Выделить чип в Elements → панель Accessibility: Name = «Field: Country, Sort order: ascending», Role = menuitem; у таблицы области — Role = menubar, Name = «Row Fields», Description = «Press Enter or Space to sort by the field, Alt + Down arrow…».
  2. NEW: выделить любую ячейку данных (`td` в области данных) → у неё aria-describedby; в Accessibility-панели Description = путь заголовков, например «Africa Cairo 2015 Q1». Развернуть группу — у новых ячеек описание уже с уточнённым путём.
В. VoiceOver (mac, 5 минут)
  1. Cmd+F5 включить; чтобы видеть текст — VO+F8 → Visuals → Show caption panel (VO = Ctrl+Option).
  2. Фокус на чип: «Field: Country, Sort order: ascending, menu item», при входе в область — «Row Fields, menu bar» + description про клавиши. Enter — label перечитан с «descending».
  3. NEW: дойти Tab'ом до ячейки данных: VO объявит значение и следом описание — путь по строке и колонке («Africa Cairo … 2015 Q1»).
  4. Контекстное меню по-VoiceOver'овски: VO+Shift+M на чипе/ячейке.
Замечания складывайте в корзинку (feedback-таблица из анонса). NVDA/JAWS-прогон — на Windows, поведение должно совпадать с пунктом Б.

Сверх must-have (PR #34375)

ЧтоКомментарий
aria-description на областях полейПодсказка о клавишах на каждом menubar-контейнере (панель и попап chooser'а); снимается у пустых областей. Первый такой паттерн в наших гридах.
Контекстное меню чипов с клавиатурыShift+F10/клавиша ≣ Menu — паритет с правым кликом; в попапе chooser'а меню нет и мышью — там сознательный no-op.
axe-тесты в CItests/accessibility/pivotGrid.ts: базовый рендер, chooser, header filter, контекстное меню.
Известные мелочи (не блокеры): нет aria-sort на чипах (состояние в label); drag-клон чипа сохраняет role="menuitem"; несортированные sortable-поля объявляют «Sort order: ascending». Тексты — черновик до техрайтеров.
