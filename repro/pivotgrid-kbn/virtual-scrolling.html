3. Virtual scrolling (обе области)

Грид 500×400, scrolling.mode: 'virtual', колонки — города (широко), строки — регион → страна → город (высоко).
  1. Tab на заголовки колонок → зажать/нажимать → много раз: фокус едет по ячейкам, область скроллится вслед за фокусом, ячейка остаётся видимой.
  2. После ререндера (виртуальная подгрузка) фокус не теряется — обводка остаётся на ячейке заголовка, стрелки продолжают работать без повторного Tab.
  3. То же для строк: Tab до заголовков строк → зажать ↓: фокус едет вниз, область скроллится, после подгрузки навигация продолжается.
  4. Проскроллить мышью далеко в сторону, кликнуть ячейку, продолжить стрелками — работает от места клика.
  5. Enter на стране (свернуть) при прокрученной области: фокус сохраняется, скролл-позиция ощутимо не прыгает.
  6. Скролл заголовков и области данных остаётся синхронным во время навигации.
  7. Новое (фикс по ревью): фокус восстанавливается по идентичности ячейки, а не по позиции. Запомнить текст сфокусированной колонки, уехать стрелками далеко (через границу виртуальной страницы, когда DOM пере-нарезается) — после подгрузки фокус на колонке с тем же текстом, не на «той же по счёту».
Известное ограничение: если групповой заголовок с colspan>1 обрезан границей страницы, его aria-colindex меняется — тогда срабатывает мягкий fallback на позицию (редкий случай: фокус именно на частично обрезанной групповой ячейке в момент пересечения границы).
