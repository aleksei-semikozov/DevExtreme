PivotGrid — Keyboard Navigation (roving tabindex)

Сборка от 2026-07-10 из стека PR (после rebase на свежий 26_1 и правок по ревью): #34202 (helper, влит) → #34203 (заголовки колонок, issue #4477, head d94cd782) → #34204 (заголовки строк, head 5350601b). База 26_1 включает ARIA-роли ячеек (#34220).

Новое после ревью (2026-07-09): восстановление фокуса при ререндере теперь идёт по идентичности ячейки (aria-colindex), а не по позиции — при виртуальном скроллинге фокус возвращается на ту же логическую колонку; раскрываемая ячейка получила aria-expanded на самом td (скринридер объявляет состояние с фокуса).

Что проверять (общий QA-чеклист)

Единый tab stop и roving tabindex

  • Tab с адресной строки: одна остановка на область заголовков колонок, затем одна на область строк. Tab больше не ходит по каждой expand-иконке.
  • Уйти стрелками на другую ячейку → Shift+Tab из грида → Tab обратно: фокус возвращается на ту же ячейку, а не на первую.
  • Клик мышью по любой ячейке заголовка: она становится текущей tab-остановкой (проверить возвратом через Tab).
  • В DevTools: в области ровно одна ячейка с tabindex="0", остальные tabindex="-1"; expand-иконки — tabindex="-1".

Активация и сохранение фокуса

  • Enter / Space на ячейке с иконкой: сворачивает/разворачивает группу, фокус остаётся на том же месте (не улетает в body), aria-expanded меняется.
  • Удержание Enter (авто-повтор) не должно многократно сворачивать/разворачивать.
  • Фокусная обводка (2px) видна при клавиатурной навигации; при кликах мышью обводки быть не должно (focus-visible).

Границы и регрессии

  • На краю области стрелка «в никуда» — фокус стоит на месте, страница не скроллится.
  • Клик по expand-иконке мышью работает как раньше; onCellClick срабатывает.
  • Навигация по полям field panel (Tab/Enter/Alt+↓) не изменилась.
  • Скролл областей остаётся синхронизированным (заголовки ↔ данные).
  • Ячейки области данных фокус не получают (по дизайну — навигация только там, где есть контролы).
На страницах с чекбоксом RTL стрелки ←/→ должны следовать визуальному направлению.
Известные ограничения (осознанные, кандидаты на обсуждение при ревью):
  • Стрелки с модификаторами (Ctrl/Alt/Cmd+стрелка) сейчас тоже перехватываются гридом — может мешать командам скринридеров.
  • Виртуальный скроллинг: групповой заголовок с colspan>1, обрезанный границей страницы, меняет aria-colindex — идентичность теряется, срабатывает мягкий fallback на позицию (поведение до фикса).
