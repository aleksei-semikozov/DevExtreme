Scheduler — Multilevel Grouping

Демка из PR #34625 к карточке 4715, собрана по Figma-макету. Библиотека — из ветки feature/scheduler-multilevel-grouping/main. Код на странице ровно тот, что уедет в apps/demos/Demos/Scheduler/MultilevelGrouping.

Что смотреть

  • Иерархия Room → Employee задаётся плоским массивом в одном dataSource ресурса плюс parentIdExpr: 'parentId'. Отдельного ресурса на уровень нет, groups остаётся ['assigneeId'].
  • Бэнды дают только листья — сотрудники. Комнаты становятся заголовками, растянутыми на своих людей. У каждой комнаты свой набор сотрудников, они не повторяются между комнатами.
  • Переключатель в тулбаре справа: Vertical Grouping ↔ Horizontal Grouping.
  • Двойной клик по встрече → в попапе два поля: Room (выпадающий список) и Employee (теговое поле, allowMultiple). Выбор комнаты фильтрует список сотрудников. Это кастомная логика демки в onAppointmentFormOpening.
  • Цвет встречи берётся из color сотрудника.
Room 1 ├── Samantha Bright └── John Heart Room 2 ├── Todd Hoffman └── Sandra Johnson

Расхождения и известные вещи

  • Иконка комнаты из макета убрана. Она делалась через resourceCellTemplate, а он рендерится по-разному в React и Angular (в React данные приходят первым аргументом, а не как { data }). Эталон скриншота в репозитории один на все фреймворки, поэтому шаблон давал красные react/angular-screenshots. Без шаблона все четыре фреймворка дают побайтово одинаковый рендер.
  • При вертикальной группировке axe находит aria-required-parent на заголовках групп. Это баг виджета, а не демки — чинится в PR #34648 (issue 4881), который в эту ветку ещё не влит.
