Agenda + группировка по ресурсам: кривые стили в generic-теме

В представлении agenda с группировкой по двум и более ресурсам generic-тема рисует разделитель группы не по границе ячейки, а под текстом заголовка — линия обрывается посреди блока. В fluent и material такого нет.

Компонент: Scheduler, currentView: 'agenda' Тема: generic (dx.light.css и остальные generic-варианты) Версия: воспроизводится на 26.1.3 (CDN) и в main (26.2.0) Условие: groups из ≥ 2 ресурсов

Живое сравнение

Смотрите на левую колонку с названиями комнат. Три примера ниже — один и тот же Scheduler, отличаются только подключённой темой.

баг generic (dx.light.css) — под «Conference Room 101» висит обрывок линии, сам текст обрезан многоточием
эталон fluent.blue.light — разделители идут по границам групп, название ресурса помещается целиком
generic + патч generic (dx.light.css) с исправленным CSS — тот же generic, но box-shadow перенесён с контента на ячейку

Что именно ломается

  • Разделитель группы обрывается посреди блока. У ячейки внешнего уровня группировки («Conference Room 101») высота 320 px, а линия нарисована на 48 px — сразу под текстом. Визуально это читается как подчёркивание надписи, а не как граница группы.
  • Название ресурса обрезается. generic жёстко задаёт width: 80px + overflow: hidden для содержимого заголовка, поэтому «Conference Room 101» превращается в «Confere… Room 101». В fluent ширина 100 px и текст переносится целиком.
  • Проявляется только при вложенной группировке. При одном ресурсе в groups всё выглядит корректно — поэтому баг и не бросался в глаза.

Причина

Generic рисует разделитель на внутреннем div’е, а не на ячейке (packages/devextreme-scss/scss/widgets/generic/scheduler/_index.scss): 

.dx-scheduler-agenda {
  .dx-scheduler-group-header-content {
    width: $generic-scheduler-group-header-table-cell-width;   // 80px
    padding: $generic-scheduler-agenda-group-header-padding;
    box-shadow: inset 0 -1px 0 0 $scheduler-accent-border-color; // ← линия по низу div'а
  }
}

Высоту этого div’а проставляет JS — но только для последнего уровня группировки. Ячейки внешних уровней объединены через rowspan и явно отфильтрованы (packages/devextreme/js/__internal/scheduler/workspaces/agenda.ts): 

private setGroupHeaderCellsHeight(): void {
  const $cells = $(
    this.getGroupHeaderCells().toArray()
      .filter((element) => !element.getAttribute('rowSpan')),   // ← rowspan-ячейки пропускаем
  );
  ...
  setOuterHeight($cellContent, this.getGroupRowHeight(rows[i]));
}

В итоге у rowspan-ячеек контент схлопывается по высоте текста, и box-shadow оказывается там же. Замеры со страницы выше:

Fluent и material этой проблемы не имеют, потому что в их agenda-секции box-shadow на .dx-scheduler-group-header-content не задаётся вовсе.

Предлагаемое исправление

Перенести разделитель с контента на саму ячейку — она уже растянута по rowspan’у, так что линия автоматически встанет по границе группы. Заодно убрать фиксированную ширину, из-за которой обрезается подпись. 

.dx-scheduler-agenda {
  .dx-scheduler-group-header {
    font-size: $generic-scheduler-group-header-agenda-font-size;
    width: $generic-scheduler-group-header-table-cell-width;
+   box-shadow: inset 0 -1px 0 0 $scheduler-accent-border-color;
  }

  .dx-scheduler-group-header-content {
-   width: $generic-scheduler-group-header-table-cell-width;
    padding: $generic-scheduler-agenda-group-header-padding;
-   box-shadow: inset 0 -1px 0 0 $scheduler-accent-border-color;
  }
}

Ровно этот CSS и подключён в третьем примере («generic + патч») — как inline-стиль поверх штатной темы, без пересборки библиотеки.

Как воспроизвести

Минимальная конфигурация — важно, чтобы в groups было ≥ 2 ресурса:

$('#scheduler').dxScheduler({
  currentDate: new Date(2018, 4, 14),
  currentView: 'agenda',
  views: ['agenda'],
  groups: ['roomId', 'ownerId'],
  dataSource: [
    { text: 'Install New Database', roomId: 1, ownerId: 1,
      startDate: new Date(2018, 4, 14, 9), endDate: new Date(2018, 4, 14, 11) },
    { text: 'Upgrade Personal Computers', roomId: 2, ownerId: 1,
      startDate: new Date(2018, 4, 15, 10), endDate: new Date(2018, 4, 15, 11, 30) },
  ],
  resources: [
    { fieldExpr: 'roomId', label: 'Room', dataSource: [
      { id: 1, text: 'Conference Room 101' }, { id: 2, text: 'Room 102' }] },
    { fieldExpr: 'ownerId', label: 'Owner', dataSource: [
      { id: 1, text: 'Alex' }, { id: 2, text: 'Samantha' }] },
  ],
});

Страница собрана на публичном CDN DevExtreme 26.1.3 — то есть баг воспроизводится на релизной сборке, а не только на локальном билде. Те же правила _index.scss и тот же фильтр по rowSpan присутствуют в main.
