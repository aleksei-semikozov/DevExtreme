PivotGrid A11y - Expand Icons Keyboard Navigation (KBN)

Test Plan

  1. Tab to expand icon cell — click on a row header with expand icon (e.g. "North America"), then use Tab to navigate. The cell with expand icon should be focusable.
  2. Enter key — focus a cell with expand icon, press Enter. It should toggle expand/collapse.
  3. Space key — focus a cell with expand icon, press Space. It should also toggle expand/collapse.
  4. aria-expanded attribute — open DevTools, inspect a header cell with expand icon. It should have aria-expanded="true" or aria-expanded="false" on the <td> element.
  5. Screen reader — if available, verify the screen reader announces expanded/collapsed state.
  6. Plain cells — cells WITHOUT expand icon should NOT have aria-expanded and Enter/Space should do nothing.
Status: Ready. Click on an expandable cell or use keyboard to test.
