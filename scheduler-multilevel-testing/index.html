Как пользоваться стендом
  • Слева — сценарии. Разделы 1–7 повторяют чек-лист задачи 4716, разделы 8–9 (метка доп) добавлены сверх плана.
  • Отметки ✓ Работает / ✗ Баг / — Не применимо и заметки сохраняются в браузере. Кнопка Отчёт собирает из них markdown для вставки в задачу.
  • Код каждого сценария редактируется внизу страницы: Ctrl+Enter — запустить, Вернуть исходный — откатить. Правки тоже сохраняются в браузере, так что перезагрузка их не потеряет.
  • Вкладка Общие данные (prelude) — общий для всех сценариев код с деревьями ресурсов и генератором встреч; в сценарии он приходит как H.
  • Внутри кода доступны H, LAB.scheduler() (живой экземпляр), LAB.log(…) (вывод под сеткой), LAB.diagnose(), DevExpress и $.
  • Диагностика под сеткой печатает дерево шапки, число листовых групп, обрезку текста с подсказками и разметку заголовков — быстрее, чем лазить в инспектор.
  • Сверху: 39 тем, ширина сцены (для адаптивности), RTL и кнопка axe (проверка доступности текущего сценария).
  • Клавиши [ и ] — предыдущий/следующий сценарий. Ссылка вида #id-сценария открывает конкретный сценарий.
  • Библиотека собрана из ветки фичи (в релизе её нет), поэтому в консоли есть предупреждения о триальной лицензии — они отфильтрованы и в панель ошибок не попадают.
