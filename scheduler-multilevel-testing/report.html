Автопрогон стенда: Scheduler · Multilevel Grouping

Playwright + Chrome, окно 1680×1200, сборка ветки фичи 26.2.0 @ c753b73d70. Проверялись: структура панели групп, попадание встреч в свои группы по геометрии, интерактив, axe и обрезка подписей. Скриншоты сняты автоматически, по одному на сценарий.

Что нашлось

  • Дубли id в источнике ресурса → две одинаковые группы и удвоенные встречи (сценарий).
  • Agenda + иерархия → панель групп не отрисована вообще: встречи идут списком без единой подписи группы (сценарий).
  • Форма отдаёт родительские узлы → выбор «Building A» и Save убирают встречу из сетки навсегда; в данных она остаётся (сценарий).
  • Встреча с id родителя молча не рисуется — ни предупреждения, ни ремарки в документации (сценарий).
  • Фильтрация ветки оставляет опустевшего родителя отдельной листовой группой (сценарий) — нужно решение команды.
  • Плоская вертикальная группировка (без иерархии) не даёт подписям ни title, ни aria-label, в иерархической они есть (сценарий).
