PivotGrid KBN — Open the cell context menu from the keyboard

How to test

  1. Focus a header cell — click inside the grid, then press Tab until a row or column header cell gets a focus outline.
  2. Open the menu — press Shift+F10 or the dedicated Menu (Context Menu) key. The menu opens anchored to the focused cell and focus moves into it.
  3. Navigate the menu — ↓/↑ to move, Enter/Space to execute, Esc to close.
  4. Focus returns — after Esc or executing an item, focus goes back to the originating cell.
  5. Row header cell exposes Expand All / Collapse All; column header cell exposes Sort … by This Column (sort by summary).
Note: some OS/browsers intercept Shift+F10 for their own context menu. If that happens, use the dedicated Menu key, or compare with a right-click which opens the same menu.
