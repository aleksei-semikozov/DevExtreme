#738 — Recurrence icon above ellipsis in appointment (all-day row)

UI · appointment · theme: Fluent Blue Light · DevExtreme 26.1

How to reproduce

  1. Look at the all-day row. Columns are narrow (week view grouped by 3 rooms), so titles truncate to '…'.
  2. Room A — a single-day recurring appointment: the ↻ recurrence icon sits ON TOP of the ellipsised title.
  3. Room B (Sat) / Room C (Mon) — appointments that cross the week boundary: the continue arrow AND the ↻ recurrence icon appear together and collide.
Expected: Ellipsis, recurrence icon and next-day arrow occupy distinct positions in the all-day row (cf. Outlook / month view).
Actual: The recurrence icon overlays the ellipsised title; where a continue arrow is also present, the two icons overlap each other.
Root cause: in week/all-day CSS (_index.scss:205-216) right padding is reserved only for .dx-scheduler-appointment-reduced, not for .dx-scheduler-appointment-recurrence — unlike month view (_index.scss:352-358), so the absolute-positioned recurrence icon (right:5px) covers the ellipsis. Overlap depends on column WIDTH, not text length. Tagged BC + Good First Issue.
